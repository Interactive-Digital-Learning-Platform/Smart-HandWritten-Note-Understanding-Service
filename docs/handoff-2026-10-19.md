## What the service does / where trained models apply

Student uploads photos -> authenticated private image storage -> Groq OCR and
cleaning -> subject/grade/lesson matching -> scoped textbook retrieval -> concept
matching -> lesson coverage/gaps -> optional study materials. Students can leave
processing and reopen a note. Errors should show safe retry/unavailability states.

**Not every Complete/Partial/Missing label is produced by our trained model.**
Ordinary lesson analysis includes AI/semantic findings. The trained models have
finite concept catalogs and evidence/review gates; do not present them as universal
grading or measures of student mastery.

- **Science V3.5:** existing English CPU linear/logistic classifier with fixed
  feature/evidence pipeline, ten supported concepts. Integrated automatically into
  supported uploads when OCR, lesson and evidence checks allow it. Used in the
  student's concept checklist. An uncertain/withheld suggestion is not a fourth
  trained class. Raw model status and displayed suggestion are distinct.
- **History V6.2:** frozen English MiniLM feature pipeline, 94 concept rubrics and
  trained SVM heads. Remains an explicit, owned-note reviewed-text model check;
  automatic History model grading is disabled. Ordinary History lesson coverage
  is not automatically this trained model's prediction.
- **ICT V3.1** was trained/integrated earlier and its artifact is packaged, but the
  current production profile disables it. Local legacy settings can differ.
- Geography sources were supplied/ingested in earlier work; a Geography model is
  not part of this release. Local isolated v2 currently has Science/History only.
- The older XLM-R/RoBERTa experiments in `CODEX_HANDOFF.md` are not the current
  deployed Science/History architecture.

Model hashes and image pins: `deployment/azure-ready-2026-10-19/release-manifest.json`.
