# Full lesson study guides — 19 October 2026

Notes-only change. The previous generator received truncated reference context and its review prompt imposed a 350–500 word summary. Structured guides for confidently matched lessons now use the complete curriculum concept checklist, chapter-bounded paginated textbook retrieval, and two-concept draft/review batches. Every concept must return a substantial explanation and valid references to its supplied source IDs before the guide can be saved. Strict JSON schema requires the response fields. App code attaches actual source filenames/pages; the generator cannot invent source IDs or borrow a different concept's references. Missing source, missing/duplicated sections, invalid references and truncated output fail the update while preserving the previous material. A separate grounding review checks the teaching text. These checks verify checklist inclusion and source provenance, not every claim's factual correctness. Earlier live runs exposed unreliable quote copying, so model-copied quotation fields were replaced by supplied source IDs; optional visual quotes retain their existing validation.

Coverage labels come from the saved analysis concept findings, matched by ID or exact normalized name; the generator cannot decide these labels. Present, partial and missing refer to the uploaded pages, not student mastery. An absent finding is shown as not checked. A checklist and per-section markers distinguish covered, partially covered and missing concepts; the latter two receive section highlighting in the Notes viewer. Existing materials remain readable. Students regenerate an old guide with Update version.

Full lesson means all concepts in the matched curriculum checklist; it is not a guarantee that the checklist includes every possible textbook fact or that OCR preserved diagrams. The source-based visuals remain optional. Unmatched or unknown-grade notes keep the existing excerpt-scoped generator and do not claim full-lesson verification. No model weights, coverage inference, authentication, ingestion code or other members' services were changed.

Structured generation has a bounded ten-minute job timeout; other materials retain their two-minute timeout. The mobile two-minute polling session still pauses with an explicit refresh, rather than polling endlessly. Generation continues in the background.
